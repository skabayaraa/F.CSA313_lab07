# BUG-02: POST /api/books буруу биетэй хүсэлтэд 400 биш 200 OK буцаадаг

Орчин:  Уншлагын жагсаалт v2.0, Firefox 131.0, Ubuntu (WSL2) дээрх node v25.9.0, 2026-10-21
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам
1. `node app.js`-ийг шинээр асаана.
2. Өөр терминалд ажиллуулна: `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'`
3. Мөн: `curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title": '`

Хүлээгдэж байсан: «Буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» (спецификаци).
Бодит үр дүн:     Хоёр хүсэлтэд `HTTP/1.1 200 OK`, биеэд `{"result":"OK"}`.

Ноцтой байдал: Major. Буруу хүсэлтийг амжилттай гэж хариулдаг тул клиент алдааг мэдэхгүй.
